# Execution Plans

Use this directory for structured agent work.

- `feature-list.json` is the task state index.
- `active/` contains active or recently completed plans referenced by the task
  state index.

For small edits, update the task state and use a short plan. For
specification, persistence, derivation, provenance, security, or harness
changes, keep enough evidence in the plan for the next agent to restart
without chat history.
