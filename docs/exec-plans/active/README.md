# Active Plans

Every non-trivial `todo`, `in_progress`, or `done` task should link a plan
from `docs/exec-plans/feature-list.json`.

Keep completed plans here until the repository has a separate completed-plan
archive.

Every plan must contain the four PDCA sections enforced by
`scripts/harness_drift.py`:

- `## Observation`
- `## Decision`
- `## Permanent Fix`
- `## Next Check`
